# What’s Plaza?
plaza is a Engine That was made completely in the web, the idea of it is to give players the ability to create games inside this engine publish them publicly and have fun around,
The best part is that the engine works entirely in the web you don’t need any download or anything, with means works in any device

https://plaza.plazoid.workers.dev
# Features:
* Plaza Studio (including mobile and desktop)
* Avatar Customization
* Creating Games
* Adding Friends
* Chatting With Others
* Publishing Games
* Physics
* Uploading Assets
* Sign In
* Log In
* Log Out
* Changing Username every 1 month
* Changing Nickname every 3 days
* Badges
A Lot Coming in the Future! Stay Tuned.
