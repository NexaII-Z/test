# Saved Projects\n\nPlaza Studio exports every saved project as a portable `.plaza` file. On browsers that support the File System Access API, projects can be written to this folder after selecting it. On iPad/Safari and other browsers without directory-write support, the `.plaza` file is downloaded to Files/Downloads so it can be moved into this folder or shared directly. The Saved Projects tab also keeps a local browser library with 3D preview thumbnails.\n
